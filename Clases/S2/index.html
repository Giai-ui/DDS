Article

La etiqueta <article> se utiliza para representar un contenido independiente y autónomo dentro de un documento HTML. Es ideal para encapsular contenido que podría ser distribuido o reutilizado de manera independiente, como una publicación de blog, un artículo de noticias, una entrada de foro, o cualquier otro tipo de contenido que tenga sentido por sí mismo.

Header

La etiqueta <header> se utiliza para representar el encabezado de un documento o sección. Es comúnmente utilizada para incluir información de identificación, como el título del documento, el autor, o cualquier otro tipo de información que se considere relevante para el inicio del contenido.

Main

La etiqueta <main> se utiliza para representar el contenido principal de un documento HTML. Es comúnmente utilizada para incluir el contenido principal del sitio web, que es único para cada página.

Section

La etiqueta <section> se utiliza para representar una sección genérica de un documento. Es comúnmente utilizada para agrupar contenido relacionado dentro de un documento, como capítulos, temas, o cualquier otro tipo de agrupación lógica de contenido.

Nav

La etiqueta <nav> se utiliza para representar una sección de navegación dentro de un documento HTML. Es comúnmente utilizada para incluir enlaces a otras partes del sitio web, como menús de navegación, enlaces a secciones específicas, o cualquier otro tipo de enlace que facilite la navegación del usuario.

Atributos

Los atributos son propiedades que se pueden agregar a las etiquetas HTML para modificar su comportamiento o apariencia. Algunos atributos comunes incluyen:

  • id: Proporciona un identificador único para el elemento.
  • class: Asigna una o más clases CSS al elemento.
  • title: Proporciona información adicional sobre el elemento, que se muestra como un tooltip.
  • href: Especifica la URL a la que enlaza el elemento.
  • src: Especifica la URL de una imagen o recurso multimedia.
  • alt: Proporciona texto alternativo para una imagen, que se muestra si la imagen no se puede cargar.
  • type: Especifica el tipo de contenido del elemento.
  • value: Especifica el valor de un elemento, como un campo de formulario.

Formularios

Sección de una página web que permite al usuario ingresar y enviar datos a un servidor web.

Los formularios se crean utilizando la etiqueta <form> y pueden contener diversos elementos de entrada, como campos de texto, botones de radio, casillas de verificación, menús desplegables, y botones de envío. Los formularios son esenciales para la interacción del usuario con el sitio web, permitiendo la recopilación de información, la realización de búsquedas, la autenticación de usuarios, y muchas otras funciones.

  • action: Especifica la URL a la que se enviarán los datos del formulario cuando se envíe.
  • method: Especifica el método HTTP que se utilizará para enviar los datos del formulario (por ejemplo, "get" o "post").
  • enctype: Especifica el tipo de codificación que se utilizará al enviar los datos del formulario (por ejemplo, "application/x-www-form-urlencoded" o "multipart/form-data").
  • name: Proporciona un nombre para el formulario, que puede ser utilizado para identificarlo en el servidor.
  • target: Especifica dónde se abrirá la respuesta después de enviar el formulario (por ejemplo, "_blank" para abrir en una nueva pestaña).
  • autocomplete: Especifica si el navegador debe habilitar o deshabilitar la función de autocompletar para los campos del formulario.
  • novalidate: Especifica que el formulario no debe ser validado antes de enviarse.
  • class y id: Se utilizan para asignar clases CSS y un identificador único al formulario, respectivamente.

Etiquetas de formulario

<form>: Se utiliza para crear un formulario HTML.

  • <input>: Se utiliza para crear diversos tipos de campos de entrada, como texto, correo electrónico, contraseña, etc.
  • <label>: Se utiliza para asociar una etiqueta descriptiva con un elemento de formulario.
  • <textarea>: Se utiliza para crear un campo de texto de varias líneas.
  • <select>: Se utiliza para crear un menú desplegable.
  • <option>: Se utiliza dentro de un elemento <select> para definir las opciones disponibles en el menú desplegable.
  • <button>: Se utiliza para crear un botón que puede ser utilizado para enviar el formulario o realizar otras acciones.
  • <fieldset>: Se utiliza para agrupar elementos relacionados dentro de un formulario, y suele ir acompañado de una etiqueta <legend> para proporcionar un título a ese grupo.
  • <legend>: Se utiliza para proporcionar un título a un grupo de elementos dentro de un <fieldset>.
  • <datalist>: Se utiliza para proporcionar una lista de opciones predefinidas para un campo de entrada, que el usuario puede seleccionar o escribir manualmente.
  • <output>: Se utiliza para representar el resultado de un cálculo o acción realizada por el usuario dentro de un formulario.

Aside

La etiqueta <aside> se utiliza para representar contenido que está relacionado de manera tangencial con el contenido principal del documento, pero que no es parte esencial de él. Es comúnmente utilizada para incluir información adicional, como barras laterales, anuncios, enlaces relacionados, o cualquier otro tipo de contenido que pueda complementar el contenido principal sin ser fundamental para su comprensión.

Footer

La etiqueta <footer> se utiliza para representar el pie de página de un documento o sección. Es comúnmente utilizada para incluir información de contacto, derechos de autor, enlaces a políticas de privacidad, o cualquier otro tipo de información que se considere relevante para el final del contenido.
