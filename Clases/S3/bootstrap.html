¿Qué es Bootstrap?

Bootstrap es un framework de código abierto para el desarrollo de sitios web y aplicaciones web, proporciona una colección de herramientas y componentes predefinidos que facilitan la creación de interfaces de usuario atractivas y responsivas.

Un diseño responsivo garantiza una experiencia de usuario consistente y óptima, independientemente del dispositivo que se esté utilizando para acceder al sitio web.

Bootstrap se basa en un sistema de cuadrícula (grid system) que permite organizar el contenido en filas y columnas, facilitando la creación de diseños flexibles y adaptables a diferentes tamaños de pantalla.

¿Cómo funciona Bootstrap?

Bootstrap está constituido por una serie de archivos CSS y JavaScript responsables de asignar características específicas a los elementos de la página.

La estructura del framework se compone de dos directorios:

  • CSS: Define el estilo visual de los elementos, como colores, tipografía, márgenes y otros aspectos relacionados con la apariencia.
  • JavaScript: Proporciona funcionalidades interactivas, como menús desplegables, carruseles de imágenes, modales y otros componentes dinámicos.

Como enlazar Bootstrap

Para utilizar Bootstrap en un proyecto, es necesario enlazar los archivos CSS y JavaScript en el documento HTML.

Existen dos formas principales de enlazar Bootstrap:

  • Enlazar desde un CDN: Puedes utilizar un enlace directo a los archivos de Bootstrap alojados en un Content Delivery Network (CDN). Esto es conveniente y rápido, ya que los archivos se cargan desde servidores optimizados para la entrega de contenido.
  • Descargar e incluir localmente: Puedes descargar los archivos de Bootstrap y alojarlos en tu propio servidor. Luego, debes enlazarlos en tu documento HTML utilizando rutas relativas o absolutas.

Componentes de Bootstrap

Bootstrap ofrece una amplia gama de componentes predefinidos que puedes utilizar para crear interfaces de usuario atractivas y funcionales:

  • Botones: Elementos interactivos que permiten a los usuarios realizar acciones específicas.
  • Formularios: Estructuras para recopilar información del usuario.
  • Tablas: Estructuras para mostrar datos en una tabla organizada.
  • Alertas: Mensajes de notificación que informan al usuario sobre estados específicos.
